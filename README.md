# Cchong Photo Studio

## 仓库与私密文件

GitHub 仓库只保存项目源码和当前安卓安装包。`android/signing/` 中的签名密钥、密码文件及 `archives/` 私密归档不会上传。若从 GitHub 克隆后要构建可覆盖安装的安卓版本，请从本机私密归档恢复签名文件；不要把它们提交到仓库。

## 1.4 使用改进

网页和安卓都支持单张照片独立调整、按住对比原图、只重试失败照片，以及动态照片视频预览。安卓批量处理改为前台服务，切到其他应用或锁屏时继续处理，进度可从通知栏查看。系统强制停止应用、取消文件访问授权或设备关机时仍可能中断任务。网页动态预览使用原视频加水印示意；最终导出仍对视频每一帧重新处理。

## Android 离线安装包

`android/` 是独立的 Android 应用。运行时不连接 NAS，也不申请网络权限；优先使用系统相册选择器批量选择已有照片（最多 100 张），在手机本地加水印，直接保存到系统相册的 `Pictures/Cchong`。旧系统没有相册选择器时会打开其他照片来源选择入口。JPEG 动态照片会拆出视频、给视频帧加水印并重新封装；如果动态内容无法识别，会报错而不会悄悄导出静态图。静态照片可使用 Android 系统能够解码的 JPG、PNG、WebP、HEIC、AVIF。动态 HEIC/AVIF 暂未在离线版中实现。小米相册对重新封装文件的动态识别仍需在真实手机上验证。

安装时打开根目录的 `CchongWatermark-offline-1.4.apk`。Android 可能提示允许从此来源安装应用。1.4 可直接覆盖安装 1.0/1.1/1.2/1.3；后续更新必须沿用 `android/signing/` 中的签名密钥。请自行备份该目录，且不要分享其中的密码。

飞牛 NAS 上运行的私有批量水印网页。通过浏览器选择已有照片，导出新的 JPEG 或 JPEG Motion Photo，原件保持不变。

## 当前支持

- JPG、PNG、WebP、HEIC/HEIF、AVIF 静态照片（输出 JPEG）
- 符合 Android Motion Photo 1.0 规范的 JPEG、HEIC、AVIF 动态照片（静帧及附带视频的每一帧均添加水印，并按原容器类型输出）
- 小米带 GainMap 的 MVIMG 动态照片：保留 GainMap、视频和静帧时间戳
- 最多 100 张批量处理；单张直接下载原格式文件，多张逐个下载，不压缩为 ZIP
- RGB 三通道叠加的单色直方图、ISO / 快门 / 光圈；缺项时补经纬度和像素尺寸
- 纯黑、纯白或按局部背景亮度自动选择
- RGB 三通道在同一图中以不同透明度叠加，保留尖峰与底部坐标轴；直方图宽度为短边 30%、高度为短边 8.7%，整体中心在照片高度 83%

水印字体使用 [Manrope](https://github.com/google/fonts/tree/main/ofl/manrope) 和 [Cormorant Garamond](https://github.com/google/fonts/tree/main/ofl/cormorantgaramond)，许可文本见 `app/fonts/`。

当前版本不支持 iOS Live Photo 直接导回系统相册。小米官方说明，第三方生成的动态照片能否在相册中播放还取决于 HyperOS 与相册版本；请用实机验证导出结果。

## 部署

在 NAS 安装 Docker 和 Compose，然后执行：

```sh
docker compose up -d --build
```

在局域网直接打开 `http://NAS地址:8088`，无需登录。若要安装为桌面 PWA，需另行配置 HTTPS 反向代理。

处理结果临时保存在容器中，一小时后删除；原始上传文件不保留。视频处理可能耗时较长，批量处理时请保持网页开启。

## 自定义水印（网页版和安卓 1.2）

可调整整体大小、直方图宽高、参数文字和署名大小、左右与上下位置。选择照片后预览第一张，可在预览图上拖动定位；“恢复默认”会重置比例、位置和颜色。导出时使用同一组设置。处理中会显示动画。

## 1.3 使用改进

网页版和安卓版都可点选待处理列表中的任意照片进行预览；水印比例、位置和颜色会分别保存在浏览器或手机本地，不保存照片。网页版批量处理逐张显示已完成进度与单张失败原因，已完成的文件可立即下载。安卓预览按屏幕尺寸解码，减少动态照片预览时的内存占用。
