# Cchong Photo Studio

## 仓库与私密文件

GitHub 仓库只保存项目源码和当前安卓安装包。`android/signing/` 中的签名密钥、密码文件及 `archives/` 私密归档不会上传。若从 GitHub 克隆后要构建可覆盖安装的安卓版本，请从本机私密归档恢复签名文件；不要把它们提交到仓库。

## 1.4 使用改进

网页和安卓都支持单张照片独立调整、按住对比原图、只重试失败照片，以及动态照片视频预览。安卓批量处理改为前台服务，切到其他应用或锁屏时继续处理，进度可从通知栏查看。系统强制停止应用、取消文件访问授权或设备关机时仍可能中断任务。网页动态预览使用原视频加水印示意；最终导出仍对视频每一帧重新处理。

## Android 离线安装包

`android/` 是独立的 Android 应用。运行时不连接 NAS，也不申请网络权限；优先使用系统相册选择器批量选择已有照片（最多 100 张），在手机本地加水印，直接保存到系统相册的 `Pictures/Cchong`。旧系统没有相册选择器时会打开其他照片来源选择入口。JPEG 动态照片会拆出视频、给视频帧加水印并重新封装；如果动态内容无法识别，会报错而不会悄悄导出静态图。静态照片可使用 Android 系统能够解码的 JPG、PNG、WebP、HEIC、AVIF。动态 HEIC/AVIF 暂未在离线版中实现。小米相册对重新封装文件的动态识别仍需在真实手机上验证。

安装时打开根目录的 `CchongWatermark-offline-1.10.apk`。Android 可能提示允许从此来源安装应用。1.4 可直接覆盖安装 1.0/1.1/1.2/1.3；后续更新必须沿用 `android/signing/` 中的签名密钥。请自行备份该目录，且不要分享其中的密码。

飞牛 NAS 上运行的私有批量水印网页。通过浏览器选择已有照片，导出新的 JPEG 或 JPEG Motion Photo，原件保持不变。

## 当前支持

- JPG、PNG、WebP、HEIC/HEIF、AVIF 静态照片（输出 JPEG）
- 符合 Android Motion Photo 1.0 规范的 JPEG、HEIC、AVIF 动态照片（静帧及附带视频的每一帧均添加水印，并按原容器类型输出）
- 小米带 GainMap 的 MVIMG 动态照片：保留 GainMap、视频和静帧时间戳
- 最多 100 张批量处理；单张直接下载原格式文件，多张逐个下载，不压缩为 ZIP
- RGB 三通道叠加的单色直方图、ISO / 快门 / 光圈；缺项时补经纬度和像素尺寸
- 纯黑、纯白或按局部背景亮度自动选择
- RGB 三通道在同一图中以不同透明度叠加，保留尖峰与底部坐标轴；直方图宽度为短边 30%、高度为短边 8.7%，整体中心在照片高度 83%

水印字体使用 [Manrope](https://github.com/google/fonts/tree/main/ofl/manrope) 和 [Cormorant Garamond](https://github.com/google/fonts/tree/main/ofl/cormorantgaramond)，许可文本见 `app/fonts/`。

当前版本不支持 iOS Live Photo 直接导回系统相册。小米官方说明，第三方生成的动态照片能否在相册中播放还取决于 HyperOS 与相册版本；请用实机验证导出结果。

## 部署

在 NAS 安装 Docker 和 Compose，然后执行：

```sh
docker compose up -d --build
```

在局域网直接打开 `http://NAS地址:8088`，无需登录。若要安装为桌面 PWA，需另行配置 HTTPS 反向代理。

处理结果临时保存在容器中，一小时后删除；原始上传文件不保留。视频处理可能耗时较长，批量处理时请保持网页开启。

## 自定义水印（网页版和安卓 1.2）

可调整整体大小、直方图宽高、参数文字和署名大小、左右与上下位置。选择照片后实时预览；“恢复默认”会重置比例、位置和颜色。导出时使用同一组设置。处理中会显示动画。

## 1.3 使用改进

网页版和安卓版都可点选待处理列表中的任意照片进行预览；水印比例、位置和颜色会分别保存在浏览器或手机本地，不保存照片。网页版批量处理逐张显示已完成进度与单张失败原因，已完成的文件可立即下载。安卓预览按屏幕尺寸解码，减少动态照片预览时的内存占用。

## 1.5 胶片扫描

网页和安卓均可选择胶片扫描模式。内置 27 款胶卷，可搜索品牌、型号、中文别名或 ISO；预设保留 ISO 搜索信息，水印仅显示胶卷型号与相机，也允许手填型号和相机。默认相机为 Pentax Espio 125M。参数行使用衬线字体，仍保持黑白单色；空项不占位，全部清空会收起参数行。整批设置、逐张设置、恢复默认、实时预览和后台任务均包含胶片参数。胶片信息由用户确认，扫描仪 EXIF 不会替代所填相机。

胶卷资料参考：[Kodak](https://kodakprofessional.com/photographers/resources)、[Ilford](https://www.ilfordphoto.com/technical-data/)、[Fujifilm](https://www.fujifilm.com/ae/en/consumer/support/films/negative-and-reversal)。列表兼容旧扫描件常见型号，不表示所有胶卷仍在销售。

## 1.6 胶卷品牌与型号

胶片模式将品牌与型号分开选择。品牌旁显示中文名称，型号列表显示中文辅助说明，并支持中文或英文搜索、自定义英文品牌和型号。输出水印组合英文品牌与型号，不包含中文辅助名称。已有的胶卷设置会自动拆分显示，参数字号与署名比例沿用上一版。

## 1.7 扩展胶卷库

胶卷库扩展为 16 品牌、123 型号，包括 Kodak VISION3 5207/5219/5213/5203、Yes!Star 巨星、Lucky 乐凯、CineStill、Kentmere、Lomography、Foma、Rollei、ADOX、Harman、ORWO、ReflxLab、AgfaPhoto 和 Ferrania 等。品牌列表从目录生成；品牌别名、电影卷编号、中文描述均支持包含搜索。水印排版和字号沿用 1.6，仍不显示单独 ISO 或中文辅助名称。

`app/static/films.json` 与安卓 `assets/films.json` 保持一致。每条包含品牌、型号、中文辅助说明、感光度资料、类型、备注和来源链接；特殊曝光指数或范围保留原标法，不把型号数字直接当 ISO。此目录供扫描件标记使用，不代表库存、在售状态或乳剂产地；分装电影卷以包装信息确认，Yes!Star 数据以销售页面为依据。详见 `docs/film-catalog.md`。

## 1.8 操作界面

添加照片入口缩小、预览可前后翻页，大小与位置默认折叠。胶片选择保留最近使用的 6 款，可一键复用；逐张调整后可取消独立设置，重新使用整批设置。网页生成按钮保持可见，窄屏输入和点击区域适配触屏；处理期间锁定设置，避免误操作。水印渲染比例和胶卷库沿用上一版。

## 1.9 安卓文件与文件夹导入

新增三个来源入口：从相册选择、从系统文件选择器多选照片、选择整个文件夹。文件夹只读取当前层的 JPG/JPEG、PNG、WebP、HEIC/HEIF、AVIF 等支持格式，不递归读取子文件夹；文件名按数字自然顺序排序。超过 50 张支持的照片时先提示检查是否选错文件夹，可重新选择或确认导入。每批仍最多 100 张，剩余容量不足时先说明并确认，仅加入按文件名排序后的可容纳部分；重复 URI 会跳过。

通过 Android Storage Access Framework 获取所选文件/目录的读取权限，权限可持久化供后台处理使用；仍为离线应用。目录统计在工作线程完成，确认前不向处理列表添加照片。`android/tests/FolderImportPlanTest.java` 验证 0/50/51/123 张、容量不足、顺序、目录过滤及去重。

## 1.10 预览交互

移除网页与安卓预览图的拖动定位操作和相关提示；大小与位置面板中的位置滑杆仍可使用。图片的 EXIF 方向标签仍在预览与导出时应用。没有方向标签的扫描件暂不自动猜测拍摄方向。


## 1.11 照片方向

预览下方提供左转、右转、还原方向和自动转正。方向独立按照片保存，不随整批水印设置或取消单独样式而改变；还原方向回到按 EXIF 方向显示的原片。先转正画面，再重新绘制水印；静态与动态导出同步处理。

自动转正使用 Duarte Barbosa 的 MIT 自然照片方向模型，NAS 在本机推理，安卓内置模型离线推理，无联网权限。点击后识别当前照片，模型分数达到 0.90 才应用；不确定时保持方向，用户可手动调整。分数不是准确率保证，抽象、倒影、俯拍等照片请检查预览。模型约 80.6 MB，安卓另需 ONNX Runtime，首次使用会将模型复制至应用私有目录。

模型来源、版本、校验值及许可证见 `app/models/README.txt` 和 `LICENSE-orientation.txt`。模型验证仅能说明测试样本的结果，不代表所有胶片扫描件。
